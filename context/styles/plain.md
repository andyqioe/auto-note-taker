#### Plain language (ISO 24495-1)

Write so that the reader can find what they need, understand it and use it on the first read.

- Know the reader: a person or an agent who did not see the work. Put what they need first.
- Use everyday words. Write "use", "start" and "about", not "utilize", "commence" and "approximately".
- Use the active voice and name the actor: "The worker sends the charge."
- Keep most sentences under 20 words and none over 30. Give each sentence one main idea.
- Keep paragraphs short, with one topic each.
- Define a term the first time you use it, then use the same term every time.
- Use a list for steps and parallel items, and a table for a comparison.
- Address the reader as "you" when you tell them what to do.
